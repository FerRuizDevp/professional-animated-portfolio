# ☄️ Professional Animated Portfolio (GitHub API)

## Description
A dynamic portfolio built with React and Vite that fetches projects 
directly from the GitHub API — no backend or manual updates needed. 
Includes smooth animations, a working contact form, and full deployment 
on GitHub Pages.

## 🛠️ Tech Stack
- React + Vite (frontend)
- GitHub API (dynamic project fetching)
- EmailJS (contact form)
- GitHub Pages (deployment)

## ✨ Features
- Fetches GitHub projects directly from the API
- Animated UI transitions throughout
- Fully responsive across mobile, tablet, and desktop
- Working contact form with real-time email delivery
